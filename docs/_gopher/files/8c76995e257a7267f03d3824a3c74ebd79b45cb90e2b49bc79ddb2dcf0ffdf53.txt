| Symptom | What to check |
| --- | --- |
| APK will not install | API level 36+, arm64-v8a compatibility, a complete APK download and Android's permission for the installing app. For updates, use the same signing identity; export before considering uninstall. |
| Trigonometric result is unexpected | DEG/RAD/GRAD indicator and any explicit angle units. |
| A number key is unavailable | Current BIN/OCT/HEX context or an active REG layer. Return to DEC or leave REG. |
| Nothing happens at equals | Empty template boxes, incomplete syntax, a busy calculation or a displayed error. |
| Output uses `≈` | Approximate inputs, irrational values or rounded presentation. Use S⇔D to inspect another representation; do not assume extra precision makes measurements exact. |
| Changing display format seems to recalculate | Use S⇔D for reformatting. SHIFT+= explicitly evaluates again. |
| Currency conversion has no rates | Complete the first refresh online, then check cache date and supported currencies. |
| A graph has gaps or misses a feature | Domain restrictions, range, selected series and sampling resolution/budget. A numerical graph is not a completeness proof. |
| A result in Steps is unsupported | Steps has a deliberately narrower exact rule set than the calculator and other workbenches. |
| No key sound/vibration | App switches, Android media volume and Android haptic settings. |
| An export is missing | Confirm that the document picker completed, check the selected destination, and distinguish Copy from Export. |
| Controls feel crowded | Try System/Medium font, a less dense keypad or landscape. Scroll the active panel to reach its remaining controls. |

For further context inside the app, open **MENU → Personalize → Guide**. When reporting a problem, include the app version, Android version, device architecture, input and relevant settings, plus a screenshot without personal information.
