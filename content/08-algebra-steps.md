Open **MENU → Calculate & explore → Algebra / Calculus**. Choose an operation, fill the expression and the fields relevant to that operation, then tap **Calculate**. The workbench offers equations, systems, inequalities, numerical roots, simplify/factor/expand, derivatives, integrals, limits, sums, products and substitution.

A first example is **Solve equation**, expression `x^2-5*x+6=0`, variable `x`, domain **Real**. The roots are 2 and 3. For **Differentiate**, use `x^3`, variable `x`, first derivative; the result is `3*x^2`. For a definite integral of `x^2`, use lower bound 0 and upper bound 1; the result is `1/3`.

Read domain restrictions and diagnostics alongside the answer. A numerical root method needs sensible starting information and does not establish that it found every root. **Insert result** returns a result to the calculator for further editing. **Accept selected replacement** applies a transformation only when the original selected input still matches.

**Details** presents a selected result and offers representations and follow-up actions. A saved result's context can differ from today's Ans, definitions or settings. Use explicit recalculation when you intend to calculate again instead of merely reformatting or inspecting it.

## Request an explanation with Steps

Open **Steps**, choose its method, enter an expression and variable, then request the derivation. For a simple first example use rational arithmetic `1/6+1/3`. Expand the individual steps to see the before/after expressions, rule and conditions. Copy the explanation or export it as PNG/PDF through the document picker.

Steps is a deterministic offline explanation tool, not a general proof engine. Its supported families include rational arithmetic, polynomial collection and selected simplification/factoring, affine/quadratic equations, selected inequalities, derivative rules, several integration families, selected limits and rational matrix procedures. Trigonometric Steps rules use **radians** independently of the calculator's display convention.

An unsupported Steps request does not imply that ordinary calculator evaluation is unavailable. Steps limits include 1,024 input characters, exact rational resource bounds, matrices up to 6×6 for row reduction, and 2×2 determinant/inverse explanations. Long derivations may need PDF rather than PNG. Preserve displayed exclusions such as `x≠1` when a factor cancels.
