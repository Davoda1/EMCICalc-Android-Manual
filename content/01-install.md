Use the signed **`EMCICalc-1.0.0-Android-arm64-v8a.apk`** package. This build requires **Android API level 36 or newer** and a device supporting **arm64-v8a**. An older Android version or an x86-only device cannot install this package.

1. Save the APK on the device and open it from your browser or file manager.
2. If Android asks, allow that browser or file manager to install this APK, then confirm the installation.
3. Open **EMCICalc**. You do not need an account or a network connection for ordinary calculations.
4. Keep the original APK and check its SHA-256 against the release checksum file if you need to verify your download.

Install later updates over the existing app using a package signed by the same publisher. Before uninstalling or clearing Android app storage, export any workspace you want to keep. Those Android actions can remove the app's saved data. A workspace export is described in [Save, export and restore work](13-save-restore.md).
